# 控制算法库

本目录提供可直接嵌入 STM32 / DSP 工程的 C 实现：

| 算法 | 文件 | 特点 |
|------|------|------|
| 绝对式 PID | `pid_positional.*` | 经典位置式，输出为绝对控制量 |
| 增量式 PID | `pid_incremental.*` | 输出为 Δu，适合执行器积分型接口 |
| LADRC | `ladrc.*` | 线性自抗扰：LESO + LSEF，一阶/二阶对象 |

## 使用建议

1. 速度环/电流环若驱动要的是“占空比绝对值”，优先**绝对式 PID**。
2. 若接口是“每次叠加增量”（步进、部分阀门/惯导修正），用**增量式 PID**。
3. 模型不确定、扰动大时尝试 **LADRC**；先调 `wo`（观测器带宽）再调 `wc`（控制器带宽）。
