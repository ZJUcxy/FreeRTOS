# 10 TMS320C6678 实战指南

目标芯片：`TMS320C6678`（8×C66x DSP）。  
例程路径：`examples/c6678/`。

> 说明：TI 生态更常见 SYS/BIOS / TI-RTOS。本指南给出 **FreeRTOS 单核运行 + 核间协作** 的工程化骨架，便于统一团队软件模型。量产前请完成 port 层与中断/Cache 验证。

## 10.1 架构建议

```text
Core0: FreeRTOS（调度、命令、汇总）
Core1..N: 独立 while 循环或独立 RTOS 实例（重算力：FFT/滤波/多轴）
共享: MSMC / DDR 描述符 + 门铃中断（IPC）
```

不要尝试“一个 FreeRTOS 调度器管 8 核”。

## 10.2 Port 关键点

| 项 | 建议 |
|----|------|
| Tick 源 | GPTimer0 周期中断 → `xPortSysTickHandler` 等价入口 |
| 上下文 | 保存 A/B 寄存器组、SP、返回指针；若用向量扩展需一并保存 |
| 临界区 | 关 CPU 中断（`CSR.GIE`）或 port 封装 |
| 栈方向 | C66x 向下增长，初始化任务栈帧需匹配 ABI |
| Cache | L1D/L2 对共享缓冲做 writeback/invalidate |

例程中的 `port_c66x_*.c` 为**教学级伪移植层**，需按你的 CCS/编译器 ABI 完善。

## 10.3 例程功能

1. Core0 启动 FreeRTOS，创建 `WorkerTask` / `IpcTask`
2. 周期任务模拟“处理负载”
3. 通过共享内存 mailbox + 软件中断通知它核
4. 提供与 STM32 例程类似的“命令队列”模式，便于团队统一接口

## 10.4 CCS 工程提示

1. 使用 TI C6000 编译器，关闭与 RTOS 冲突的自动 RTS 钩子（按 port 要求）
2. 链接脚本明确：代码/堆/任务栈、MSMC 共享段
3. 多核工程用 IPC/Notify 或手写 doorbell
4. 先在 Core0 单核验证 Tick 与任务切换，再开核间

## 10.5 与 STM32H7 的差异对照

| 点 | STM32H7 | C6678 |
|----|---------|-------|
| 官方 port | 成熟 | 需自研/裁剪 |
| 中断控制器 | NVIC | INTC + CIC |
| 内存 | TCM/AXI SRAM | L2/MSMC/DDR |
| 典型任务数 | 较多细粒度 | 较少粗粒度 |
| 核间 | HSEM/OpenAMP | 共享内存 + 门铃 |
